# 论文格式检查助手（首版）

这是一个面向 Windows 的本地 Word 论文格式检查工具。文件只在本机解析，不上传网络。

## 已实现

- 读取 `.docx` 论文与 `.docx` 学校模板
- 对比纸张、页边距、页眉页脚距离和分节设置
- 识别中文章节标题、数字编号标题和 Word Heading 样式
- 检查标题层级、编号连续性及正文中的疑似标题样式错误
- 对照目录文字与正文标题
- 检查图、表题注编号连续性及正文引用
- 检查顺序编码制引用与文末参考文献的缺失、多余和越界
- 检查页码域、目录域和不同分节页码设置
- 提取教师批注及对应段落，作为检查提示
- 导出 HTML、CSV 和 JSON 检查报告

## 运行

安装 Python 3.11 或更高版本，在本目录运行：

```bat
py -m pip install -r requirements.txt
py main.py
```

## 构建 Windows EXE

双击 `build_windows.bat`。构建结束后，程序位于：

```text
dist\论文格式检查助手.exe
```

## 当前边界

- 旧版 `.doc` 需要先用 Word 或 WPS 另存为 `.docx`。
- Word 的动态目录和页码可能尚未更新；工具检查的是文档内保存的字段和文字。
- 页码精确定位依赖 Word 排版引擎，首版以段落序号、章节和问题文本定位。
- 首版只检查并生成报告，不自动修改原论文。
